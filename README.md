# simple-springboot

『スッキリわかるサーブレット＆JSP入門 第5版』第15章の内容に沿った、
Spring Boot（Maven + VS Code）のスモールステップ・カリキュラムです。

- [`curriculum/`](curriculum/README.md) — レッスン00〜10（Markdown）
- [`demo/`](demo) — 全レッスンの完成コード（Spring Boot 4.1.1 / Java 21 / Thymeleaf + JSP / Lombok）

## 起動方法

```powershell
cd demo
.\mvnw.cmd spring-boot:run
```

<http://localhost:8080/> を開くと、各レッスンのページへのリンクが表示されます。
